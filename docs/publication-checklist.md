# Publication Checklist

Status: draft.

Use this checklist before changing repository visibility or publishing public-facing content.

## Repository visibility

- [ ] Repository is intentionally private-first during drafting.
- [ ] Human approval is recorded before any visibility change to public.

## Content safety

- [ ] No secrets or credentials.
- [ ] No internal hostnames.
- [ ] No private operational paths.
- [ ] No private runbook details.
- [ ] No unapproved screenshots.
- [ ] No private artifact paths.
- [ ] No private evidence packets.

## Claim safety

- [ ] Current capability, limitation, roadmap, and speculation are separated.
- [ ] Technical claims are listed.
- [ ] Technical review is complete where required.
- [ ] UX/readability review is complete where needed.
- [ ] QA link/Markdown/private-reference check is complete where needed.

## Final approval

- [ ] Human publication approval is explicitly recorded.
- [ ] Publication scope is exact.
- [ ] Remaining risks are listed.
