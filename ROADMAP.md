# Roadmap

Status: draft. Not approved for public publication yet.

This roadmap is intentionally high-level until public claims are reviewed.

## Phase 1: private-first public repository preparation

- Create repository skeleton.
- Add public-content review checklist.
- Draft README, manifesto, product overview, FAQ, limitations, examples, and roadmap.
- Review technical claims before publication.
- Keep repository private until Human publication approval.

## Phase 2: public narrative and examples

- Prepare a small set of approved public examples.
- Separate current capability from future roadmap.
- Add public FAQ entries.
- Add clear limitation statements.

## Phase 3: public release readiness

- Run Technical review for claims.
- Run UX/readability review for public pages.
- Run QA checks for links, Markdown rendering, and private-reference leaks.
- Record Human publication approval.
- Switch repository visibility only after explicit approval.

## Not committed yet

The following are not public commitments until reviewed and accepted:

- specific feature timelines;
- supported circuit categories;
- simulation accuracy claims;
- integration promises;
- commercial or pricing claims.
