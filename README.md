# AI Electronics Lab

Public-facing home for AI Electronics Lab.

AI Electronics Lab is being prepared as a public product and community space for exploring electronics workflows with AI-assisted explanation, simulation artifacts, and clear engineering caveats.

This repository is private-first while the public content is being reviewed. Publication requires explicit Human approval.

## Publication rule

No public claim about electronics correctness, SPICE behavior, schematic validity, hardware safety, calculation accuracy, or production readiness should be published until it has passed the appropriate review path.

Required review path for public content:

1. `community_content_agent` drafts or edits public-facing Markdown.
2. `technical` reviews electronics, SPICE, schematic, calculation, safety, and hardware-validity claims.
3. `ux_ui_designer_agent` reviews wording, structure, and reader clarity when needed.
4. `qa_agent` checks links, Markdown rendering, file paths, and obvious private/internal references when needed.
5. Human approves publication.

## Private-first note

Do not add secrets, credentials, internal hostnames, private runbook details, unapproved screenshots, internal artifact paths, or private operational evidence to this repository.
